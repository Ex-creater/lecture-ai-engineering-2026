## 宿題

- 取り組んだレベル：基礎
- やったこと：`app/config.py` の `RAG_TOP_K` だけを5から3に変更した。1回の検索で返す候補ページの上限を減らしても、回答に必要な根拠が残るかを調べた。
- 比較した質問と、固定した条件：上記と同じLoRA・QLoRAの質問を使った。モデル、検索DB、検索方式を固定し、変更前後とも同じ `uv run python -m app.agent --trace` コマンドで実行した。
- 結果：

| ツール名・回数 | `search_materials` を1回 | `search_materials` を1回 |
| 実際の検索語 | `LoRA 固定 学習 QLoRA 加える` | `LoRA 固定 学習 QLoRA 加える` |
| 先頭に表示された検索結果 | `lec02-main-p052` | `lec02-main-p052` |
